# RÉVÉLA — The Thought Revolution

Premier MVP éditorial de **RÉVÉLA**, une maison contemporaine consacrée à la conscience humaine. Cette landing page immersive présente l’ebook *The Thought Revolution* et propose une inscription de démonstration, sans transmission ni stockage de données.

## Stack

- [Astro](https://astro.build/)
- TypeScript
- CSS natif

## Lancer le projet

```bash
npm install
npm run dev
```

Le site est alors disponible sur `http://localhost:4321`.

## Commandes

| Commande | Action |
| --- | --- |
| `npm run dev` | Lance le serveur de développement |
| `npm run build` | Génère la version de production dans `dist/` |
| `npm run preview` | Prévisualise la version de production |
| `npm run check` | Vérifie les fichiers Astro et TypeScript |

## Contenu provisoire

Les textes éditoriaux et la couverture de l’ebook sont volontairement indiqués comme provisoires. Le formulaire reproduit le parcours utilisateur final côté navigateur : aucune adresse email n’est envoyée ou conservée.
